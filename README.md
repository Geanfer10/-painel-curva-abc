# Painel Curva ABC · Ampliação Estrutural DMP/DPA

Página publicada pelo GitHub Pages. Ela lê `dados/planilha.xlsx` direto no navegador e monta a Curva ABC (A ≤ 80%, B 80–90%, C > 90%) de cada aba que tenha as colunas **Descrição** e **Preço Total**.

A planilha é atualizada automaticamente pelo robô instalado no computador do responsável. Não edite `dados/planilha.xlsx` por aqui.
